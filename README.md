Project Name: Content Maturity, Release Lifecycle & Playlist Rotation Analysis of Spain Top 50 Songs

Project Requirements:
1. Python
2. Pandas
3. NumPy
4. Matplotlib
5. Seaborn
6. Plotly
7. Streamlit
8. Jupyter Notebook / Google Colab
9. Power BI (optional)

Dataset:
- Spain Top 50 Spotify chart dataset
- Data cleaning and preprocessing
- Missing-value and duplicate checks
- Song and artist analysis
- Chart position and popularity analysis
- Song lifecycle classification
- Playlist entries, exits, and rotation analysis
- Content attribute analysis

Dashboard Requirements:
- Key performance indicators (KPIs)
- Lifecycle stage distribution
- Daily playlist entries and exits
- Monthly playlist churn
- Explicit vs. non-explicit content analysis
- Single vs. album comparison
- Song duration vs. chart longevity
- Interactive filters for date, lifecycle stage, explicit content, and album type

Deployment Requirements:
- GitHub repository
- Streamlit Community Cloud
- requirements.txt
- app.py
- Cleaned and processed CSV files
- Jupyter Notebook (.ipynb)

link -> https://song-lifecycle-dashboard.streamlit.app/
